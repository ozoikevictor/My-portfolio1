I Must Explain To You How All This Mistaken Idea

Home / Blog / Mistaken Idea

There's a common assumption that a website is "done" the moment every section has content in it. In practice, that's usually the halfway point. What separates a finished-looking site from a genuinely finished one is everything that happens after the first draft: spacing gets tightened, copy gets trimmed, and things that seemed fine in isolation get reconsidered next to everything around them.

This mistaken idea — that filling every section is the same as finishing the project — is one of the most common traps in web design, especially for anyone building their first few sites. It's an easy trap to fall into, because progress feels obvious early on and slows down considerably during the polishing phase.

"The last ten percent of a project is where most of the actual craftsmanship lives."

Signs a Project Isn't Actually Finished

  • Spacing between sections was never compared side-by-side.
  • The mobile version was checked once, not tested through an actual phone.
  • Placeholder text is still sitting in a "final" section.
  • Nobody outside the project has looked at it yet.

None of this is about perfectionism — a project can absolutely ship with rough edges. The point is knowing the difference between "content is in place" and "this is ready," so that call is made on purpose instead of by accident.
